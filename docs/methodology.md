# 方法论

## 一句话

以个人实践为锚，把外部材料往回织进主题判断，又主动逆着锚点找反例。编译大于检索。

## 核心理念

- **编译 > 检索**：不靠 RAG / 向量库临时拼检索结果，而是把材料人工 + AI 编译成主题页里的当前判断。问答时优先读编译层，不重扫全部原料。
- **反确认偏误**：材料入库时就标注性质（支持 / 补充 / 修正 / 反驳 / 无关）；主题页强制「挑战视角」章节；问答显性呈现矛盾。以个人为锚，又主动逆锚找反例。
- **往回织不往后堆**：每条新材料都织进相关主题页、标矛盾，不是新增孤岛笔记。
- **原料只读**：`raw/`、`articles/` 永不改写，错了能回退。
- **机械归脚本，语义归 AI**：索引、校验、回顾等机械工作归 Python 脚本；摘要、判断、往回织等语义工作归 AI agent（见 `AGENTS.md`）。

## knowledge_role 三分

每篇笔记用 `knowledge_role` 标明它在知识系统中的角色，三类不能互换：

| 角色 | 含义 |
|---|---|
| `personal_basis` | 个人实践与认知基准（你的文章、你的想法） |
| `curated_influence` | 你主动整理、影响你认知的外部内容 |
| `external_input` | 后来进入知识库、等待比较和吸收的外部材料 |

**编译顺序固定**：先用 `personal_basis` 确定问题与基准，再用 `curated_influence` 解释认知来源和演进，最后用 `external_input` 补充、强化、修正或反驳。外部证据不能冒充个人实践。

`source_type`（web / own_article / own_thought）只表示原料渠道，与 `knowledge_role` 正交。

## 主题页

主题页是跨笔记的当前综合判断，不是摘要拼接。必含章节：当前结论、个人基准、重要认知来源、外部输入、材料如何互相影响、边界与矛盾、挑战视角、待验证问题、来源。其中「当前结论 / 边界与矛盾 / 挑战视角 / 待验证问题 / 来源」由 `validate.py` 强制。

## 三条取用流

- **问答流**：先读 INDEX -> 主题页 -> 笔记 -> 原料，编译层优先，不重扫。
- **选题流**：从主题页的矛盾和待验证问题生成候选，要求相对已有判断产生认知增量。
- **回顾流**：`review.py` 输出全库状态快照，不绑定周期。

## 技术选型

纯文件 + Markdown + frontmatter，零数据库 / 零向量库 / 零 RAG。

# 自定义

## 标签体系

`AGENTS.md` 里维护你的固定标签列表。原则：

- 标签表示主题或概念，不表示来源格式。
- 读完全文后选 3-5 个最贴切的；不凑数，不加弱相关。
- 不临时创造近义标签；没有合适的就记「标签提案」，本次不加。

改 `AGENTS.md` 的标签列表即可。示例标签（按你的领域调整）：`工具使用`、`方法`、`实践复盘`、`概念辨析`……

## 外部发现源（可选）

本骨架不绑定任何外部发现工具。如果你想接入一个「每天发现候选材料」的源（RSS、AI 资讯、搜索订阅等），通用框架是：

1. **发现**：拉取候选，去重。
2. **评分**：按对你当前实践的相关度打分（不只是主题相似）。
3. **性质标注**：每条标注 支持 / 补充 / 修正 / 反驳 / 无关。反驳类即使相关度低也保留。
4. **确认入库**：发现不等于入库。只有你确认后，才读全文、存 `raw/`、写笔记、往回织。

你可以用一个 `state/` 下的文件记录游标和已处理 ID（本骨架的 `validate.py` 不强制其格式，留给你实现）。

## 写作 Skill（可选）

如果你用 AI agent 辅助写作，可以在选题确认后调用你自己的写作 Skill。本骨架的选题模板（`templates/brief.md`）提供 HKR 自评（有趣 / 信息量 / 共鸣），你可按需替换为自己的质量门槛。

## 个人化

`AGENTS.md` 是给 AI agent 的运行规则，按你的实践改。`ARCHITECTURE.md` 的架构图是通用的，一般不用改。
